# Frontend

React web application for the Explainable RAG system.

## Setup (to be done in Step 4)
```bash
npx create-react-app .
# or
npm create vite@latest . -- --template react
```

## Features (planned)
- Document upload (PDF, DOCX)
- Chat-style Q&A interface
- Explainability panel showing sources, confidence, and retrieval trace
- Document management
